# ECP Series Index

[`index.json`](index.json) is the machine-readable index of assigned ECP numbers. Maintaining it is an editor responsibility under [ECP-0](../ECPs/ecp-0000.md).

Every entry carries a `provisional` flag. While it is `true`, the status reflects the founding author acting as provisional editor rather than a community determination — the series has not yet been ratified.

`status` values are drawn from the lifecycle table in ECP-0 and are listed in `statusVocabulary`.

This is not the Ethics Case Decision Registry. That is a separate dataset, in a separate repository, under CDLA-Permissive-2.0 — see ECP-2.
